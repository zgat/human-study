# 1 筋膜与连接链说明

在“综合图谱 → 筋膜力线”中勾选连接链，点“观察这组结构”显露对应组织并自动取景，再点连接参考区查看局部。也可全选后使用“观察已选结构”一起查看。完整皮肤会遮挡深层线，观察操作会隐藏皮肤。

细实线沿真实网格采样，帮助辨认涉及组织的范围，不代表肌纤维或筋膜纤维的精确走向；虚线表示局部跨组织关系，菱形表示连接参考区。隐藏皮肤或使用半身透视时，点线按关系示意叠加，不保证被其他深层组织正确遮挡。这些标记不提供受力数值、方向或治疗操作。

## 1.1 连接参考区与触发点

本版连接参考区用于学习肌肉、筋膜、腱膜、肌腱与骨之间的空间和组织关系。标记位于实际网格表面，代表观察区域，不能视为精确附着边界或临床治疗靶点。

肌筋膜触发点是需要结合个体检查判断的临床概念；2018 年国际 Delphi 共识讨论紧张带、敏感点与牵涉痛等诊断特征，并指出不应期待固定的点位及牵涉范围。本版没有将触发点做成全人群通用坐标。[诊断共识](https://pubmed.ncbi.nlm.nih.gov/29025044/)

《解剖列车》是 Thomas Myers 的肌筋膜连接学习体系；其全身链条、手法应用与本版引用的局部研究不是同一覆盖范围。本版未收录整套线路或教材图示。[官方介绍](https://www.anatomytrains.com/about-us/)

## 1.2 命名与证据基准

FIPAT《Terminologia Anatomica》第 2 版用于解剖结构命名。全国科学技术名词审定委员会《人体解剖学名词》可作为中文核名基准；本版中文名称和组织配准仍待专业人员逐项核查，不能把参考了命名资料写成全部已审定。[TA2](https://fipat.library.dal.ca/ta2/)、[全国名词委人体解剖学名词审定委员会](https://www.cnterm.cn/jggk/sdfwyh/rtjpxmcsdwyh/)

Fascia Nomenclature Committee 的 2019 年共识区分单个可解剖筋膜与广义筋膜系统。该共识用于术语范围，不提供一套全身筋膜力线或治疗靶点坐标。[筋膜命名共识](https://doi.org/10.1002/ca.23423)

解剖连续性、实验条件下的传力、人体运动中的作用和临床疗效是不同层次的证据。应用中的无箭头虚线只表达引用研究讨论的局部连接，不能由它推断某人的实际应力、远端症状病因或治疗部位。

## 1.3 当前覆盖与使用

| 局部研究连接 | 模型与观察范围 | 研究入口 |
| --- | --- | --- |
| 背阔肌—胸腰筋膜—对侧臀大肌 | 使用实际肌肉及胸腰筋膜网格，展示两种跨侧组合 | [尸解与牵拉研究](https://pubmed.ncbi.nlm.nih.gov/7701385/)、[体内实验](https://pubmed.ncbi.nlm.nih.gov/23394717/) |
| 跟腱—跟骨邻区—足底腱膜 | 使用实际肌腱、跟骨及足底腱膜；腱周组织和骨膜没有独立网格，不将其冒充为已完整建模 | [尸解、组织学与影像研究](https://pubmed.ncbi.nlm.nih.gov/24028383/) |
| 股二头肌长头—坐骨结节邻区 | 展示长头整体范围、近端与局部骨面参考区；骶结节韧带未提供独立网格 | [牵拉研究](https://pubmed.ncbi.nlm.nih.gov/20058466/)、[超声、尸解与组织学研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11353185/) |
| 臀大肌—髂胫束 | 双侧臀大肌附着邻区与髂胫束的真实网格；不将单一髂胫束网格视为已完整分层 | [尸解研究](https://pubmed.ncbi.nlm.nih.gov/24139012/) |
| 阔筋膜张肌—髂胫束 | 展示张肌与髂胫束范围及邻近连接，不计算髋膝受力 | [解剖与力学研究](https://pubmed.ncbi.nlm.nih.gov/15378277/) |
| 掌长肌—腕屈肌支持带 | 使用前臂肌肉及支持带网格；掌腱膜、鱼际筋膜与腱性扩展缺少独立网格 | [上肢尸解研究](https://pubmed.ncbi.nlm.nih.gov/17574470/) |
| 腹横肌—胸腰筋膜 | 展示腹横肌及胸腰筋膜中层、后层的分支关系；腹横肌腱膜未独立分区 | [尸解研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2140134/)、[牵拉实验](https://pubmed.ncbi.nlm.nih.gov/14722403/) |

七组共14个双侧或跨侧实例、38个连接参考区，另有32条沿相关肌肉、肌腱、腱膜和筋膜网格表面的组织范围参考段。范围段在原三角面走廊内收紧路径，避免沿面中心折返产生锯齿；起止点保持不变。连接区与组织范围样本均保留源节点、三角形与重心坐标，供重建和几何核验；标准／流畅档的几何差异不等于医学定位误差已通过验收。全部参考区及补充筋膜配准的专业审校完成数为 0。

新增内容没有补画缺少真实网格的骶结节韧带、跟骨骨膜等组织，也没有将腹壁跨中线或整套《解剖列车》概念线路画成已核实的完整链。两套来源模型仍采用整体平移配准，专业逐点配准与连接区审校尚未完成。

“筋膜·腱韧带”是显示分组，包含不同类型的结缔支持组织，每项显示具体组织类型。左右斜方肌升部、降部归肌肉；腹白线归腱膜性交织结构；原“器官体部”已依据同一源元件的具体概念改为胸骨体，剑突也归骨性结构。脑室等腔隙单独作为参考模型，不作为实体器官组织展示。

各研究链的网格缺失和证据说明在应用内离线可读；来源 URL 作为出处文本提供。完整构建、几何与设备验证范围见 [验收报告](验收报告.md)。
