# 1 验收报告

当前源码与本地安装包为“人体研究”学习测试版 **0.5.0**，包名 `com.zga.meridianatlas`，Android 10 以上、arm64-v8a。编译、安装、功能回归、性能与医学审校分别判断。

## 1.1 本版验证

本版以真实筋膜解剖为默认入口，按区域搜索、独显筋膜、腱膜与支持带。新增52片真实源网格，原1239个部件的元数据和几何不变；全部既有穴位锚点、38个筋膜参考区与48条示意段的几何保持不变。七组局部关系分别列出14项研究记录：7项解剖连续、5项实验加载、2项人体间接观察；16条关系段关联相应记录，32条组织范围辅助段不关联传力证据且默认关闭。关系线、辅助线与参考区独立控制。

构建采用 Filament 1.78.0、AGP 8.13.2、Gradle 8.14.3、Kotlin 2.2.21，SDK Platform 37.0、Build Tools 35.0.0、Temurin JDK 21.0.12.1。编译 SDK 不代表最低运行版本；AGP 对 compileSdk 37 保留兼容性提示。

本轮79项JVM单元测试通过；37项主机Python检查通过，包含8项曲面几何、6项逐段证据及3项公开证据隐私检查。Debug、Release、AndroidTest编译通过，lint为0错误、18个既有警告。新增3项筋膜证据与解剖目录设备用例已编译，但未执行。两档模型完整验证通过，原部件的节点、材质、访问器和几何payload均保持；52片新增薄片两档拓扑一致，部分源片存在非流形边，未补洞或重建为包膜。

当前编译类读取真实数据完成40994条主机领域断言，涵盖研究字段解码、路径关联、8种开关组合、三模式状态模型、1291部件/1112交互组及64项筋膜解剖目录；这不是40994项单元测试，也没有执行Android DataStore落盘。

已查看真实GLB生成的正、背、侧离线几何预览，仅用于检查覆盖与共同坐标，不代表Android实际画面。自动发现未找到已配对设备，本版尚未安装、启动或完成真机视觉/性能验收。历史设备条件为OPD2404、API36、arm64，不是最低配置。离线包检查核对无INTERNET权限和随包资产哈希，不能替代断网首次启动实测。

本版测试汇总与逐项限制见[本轮验证](validation/fascia-standards.json)、[测试汇总](validation/test-summary.json)及[构建与APK证据](validation/build-evidence.json)。[v0.5.0 Release](https://github.com/zgat/human-study/releases/tag/v0.5.0)提供可安装APK、源码包和SHA256SUMS。APK沿用本地测试签名；自行构建的签名不同，不能直接覆盖发布APK。

32条组织范围段包含1692个真实表面样本，固定端点且受原三角面约束，最大间距约8mm，流畅档表面最大差约3.77mm。几何一致不证明医学定位或传力。上一版的曲线收紧与相机领域结果保留在[筋膜优化核验](validation/fascia-expansion.json)，不作为本版设备验收。

半身透视启用肌肉并按原始人体正中矢状面裁切指定侧的皮肤、肌肉和眼口外表面；另一侧保留原色与外观，深部内脏、骨骼和牙齿完整显示。体表预设保持眼口外表面可见，旧版半身偏好仅迁移一次。0.3.2 两档全部节点的原色解析及纯领域策略曾在主机检查通过，但尚未取得 Android 实际左右画面对比，见 [半身五官核验](validation/half-face.json)。

## 1.3 功能回归范围

0.2.2 Debug 的完整设备套件发现 22 项，21 项执行通过、1 项持续手势用例默认跳过，无失败。覆盖三模式目录和图层、全局搜索、人体穴位点按、所属经络、逐块隐藏、浮卡不缩小视口、口腔多点、定位恢复、半身观察、临时经络切换不丢失选点，以及筋膜分类、图层和双档参考区坐标。本次0.5.0保留这些功能；历史完整套件与本轮单元/主机结果在测试汇总中分列，未将历史结果算作本版完整重跑。

紧凑布局曾在该平板内使用 420×760 dp 约束测试，不能替代另一台实体手机。尚未完成 Android 10 实机、实体纵向布局、另一台手机或 16 KiB 页设备测试；APK 静态 16 KiB 对齐检查不等于相应设备运行通过。

## 1.4 性能与使用边界

0.2.2 Debug 标准档肌肉模式曾完成约 65 秒持续手势短测：3,852 个模型呈现间隔，约 59.23 次/秒，P50/P95/P99 分桶为 16/25/25 ms，系统记录丢弃帧 0。该结果为历史短测；0.5.0尚未完成十分钟持续性能或Release性能测量，不能据此保证所有机型达到 30 FPS。

体表实线用于教学示意；脏腑关系虚线只表示区域关系，不表示精确深部循行。筋膜连接只表达引用研究讨论的局部组织关系，不表示精确纤维轨迹、力的数值、症状病因或治疗靶点。口腔不支持任意张口、抬舌或翻唇动画。传统主治用于文献学习，不等同于现代临床疗效证据；本应用不提供针刺操作指导。
