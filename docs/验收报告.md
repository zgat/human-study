# 1 验收报告

当前交付为“人体研究”学习测试版 **0.3.0**，包名 `com.zga.meridianatlas`，Android 10 以上、arm64-v8a。编译、安装、功能回归、性能与医学审校分别判断。

## 1.1 本版验证

本版统一安装名称、主界面标题与关于页名称，关于页版本读取构建版本；包名及模型坐标保持不变。构建采用 Filament 1.78.0、AGP 8.13.2、Gradle 8.14.3、Kotlin 2.2.21，SDK Platform 37.0、Build Tools 35.0.0、Temurin JDK 21.0.12.1。编译 SDK 不代表最低运行版本；AGP 对 compileSdk 37 保留兼容性提示。

本版构建、单元测试、lint 和真机安装结果见 [测试汇总](validation/test-summary.json) 与 [构建及 APK 证据](validation/build-evidence.json)。发布文件和 SHA256SUMS 见 [v0.3.0 Release](https://github.com/zgat/human-study/releases/tag/v0.3.0)。APK 使用本地测试签名，私钥不随源码分发；自行构建的签名不同，不能直接覆盖此发布 APK。

本轮因已配对设备暂不可发现，0.3.0 尚未完成安装与运行验证；APK 静态名称检查通过，不能代替真机显示验收。历史设备条件为 OPD2404、API 36、arm64，不是最低配置。离线依赖以 APK 无 INTERNET 权限及随包内容检查判断。

## 1.3 功能回归范围

0.2.2 Debug 的完整设备套件发现 22 项，21 项执行通过、1 项持续手势用例默认跳过，无失败。覆盖三模式目录和图层、全局搜索、人体穴位点按、所属经络、逐块隐藏、浮卡不缩小视口、口腔多点、定位恢复、半身观察、临时经络切换不丢失选点，以及筋膜分类、图层和双档参考区坐标。本次 0.3.0 保留这些功能；旧完整套件与本轮名称验证在测试汇总中分列，未将历史结果算作本版完整重跑。

紧凑布局曾在该平板内使用 420×760 dp 约束测试，不能替代另一台实体手机。尚未完成 Android 10 实机、实体纵向布局、另一台手机或 16 KiB 页设备测试；APK 静态 16 KiB 对齐检查不等于相应设备运行通过。

## 1.4 性能与使用边界

0.2.2 Debug 标准档肌肉模式曾完成约 65 秒持续手势短测：3,852 个模型呈现间隔，约 59.23 次/秒，P50/P95/P99 分桶为 16/25/25 ms，系统记录丢弃帧 0。该结果为历史短测；0.3.0 尚未完成十分钟持续性能或 Release 性能测量，不能据此保证所有机型达到 30 FPS。

体表实线用于教学示意；脏腑关系虚线只表示区域关系，不表示精确深部循行。筋膜连接只表达引用研究讨论的局部组织关系，不表示精确纤维轨迹、力的数值、症状病因或治疗靶点。口腔不支持任意张口、抬舌或翻唇动画。传统主治用于文献学习，不等同于现代临床疗效证据；本应用不提供针刺操作指导。
