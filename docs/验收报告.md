# 1 验收报告

当前源码与本地安装包为“人体研究”学习测试版 **0.4.0**，包名 `com.zga.meridianatlas`，Android 10 以上、arm64-v8a。编译、安装、功能回归、性能与医学审校分别判断。

## 1.1 本版验证

本版将筋膜内容扩展为七组有研究出处的双侧或跨侧连接，并补充沿真实组织网格采样的范围参考段；实线和虚线分别表达组织范围与局部连接。支持全选、单组或已选组织取景、分组展开及连接区定位。数字颜色值读取已修正，各组按资料配色显示。三个模式保留肌肉、骨骼、内脏、皮肤的独立快捷开关。经络目录打开或高亮穴位改变时，自动展开所属经络或奇穴部位并滚动定位；已有搜索时保持全局查询，清空后返回所属分组。经络与奇穴分类各自提供全选、全不选、全部展开和全部收起，操作保留已选穴位，勾选与展开分别控制。原始模型、穴位坐标与此前20个筋膜连接参考区保持不变。构建采用 Filament 1.78.0、AGP 8.13.2、Gradle 8.14.3、Kotlin 2.2.21，SDK Platform 37.0、Build Tools 35.0.0、Temurin JDK 21.0.12.1。编译 SDK 不代表最低运行版本；AGP 对 compileSdk 37 保留兼容性提示。

本版构建、单元测试、lint 和真机安装结果见 [测试汇总](validation/test-summary.json) 与 [构建及 APK 证据](validation/build-evidence.json)。已公开发布的上一版文件和 SHA256SUMS 见 [v0.3.0 Release](https://github.com/zgat/human-study/releases/tag/v0.3.0)。APK 使用本地测试签名，私钥不随源码分发；自行构建的签名不同，不能直接覆盖此发布 APK。

本轮因已配对设备暂不可发现，0.4.0 尚未完成安装与运行验证；APK 静态名称检查通过，不能代替真机显示验收。历史设备条件为 OPD2404、API 36、arm64，不是最低配置。离线依赖以 APK 无 INTERNET 权限及随包内容检查判断。

本轮 75 项 JVM 单元测试通过（新增 6 项覆盖筋膜曲线类型、遮挡策略、坐标保持及观察范围取景）；Debug、Release、AndroidTest 编译通过，lint 0 错误、18 警告。本轮新增 2 项 Android 筋膜扩展交互测试已编译但未在设备上执行；JVM 核心运行不代替 Android 界面、Room 或实际高亮画面验收。0.3.3 曾用真实 413 条穴位及 20 条经络核对目录核心的全部主经/奇穴部位目标，1,331 个列表布局与 434 组跨分类查询通过；这属于主机领域验证，不代表实际滚动像素。对应历史控制与目录核验见 [交互核验](validation/mode-controls.json)。同名组织的真实模型领域核验为 0.3.1 历史结果，见 [同名组织核验](validation/structure-groups.json)。

筋膜本轮完成 8 项主机几何测试：32 条组织范围段、1,692 个真实表面样本，逐段受原三角面约束，固定端点的路径收紧不增长度；最大间距约 8 mm，流畅档表面最大差约 3.77 mm。当前编译的内容解码与覆盖构建还验证了 7 种颜色、全部坐标及法线、六种皮肤/半身状态；这些结果不代表 Android 像素或真实传力。完整范围见 [筋膜优化核验](validation/fascia-expansion.json)。

半身透视启用肌肉并按原始人体正中矢状面裁切指定侧的皮肤、肌肉和眼口外表面；另一侧保留原色与外观，深部内脏、骨骼和牙齿完整显示。体表预设保持眼口外表面可见，旧版半身偏好仅迁移一次。0.3.2 两档全部节点的原色解析及纯领域策略曾在主机检查通过，但尚未取得 Android 实际左右画面对比，见 [半身五官核验](validation/half-face.json)。

## 1.3 功能回归范围

0.2.2 Debug 的完整设备套件发现 22 项，21 项执行通过、1 项持续手势用例默认跳过，无失败。覆盖三模式目录和图层、全局搜索、人体穴位点按、所属经络、逐块隐藏、浮卡不缩小视口、口腔多点、定位恢复、半身观察、临时经络切换不丢失选点，以及筋膜分类、图层和双档参考区坐标。本次 0.4.0 保留这些功能；旧完整套件与本轮名称验证在测试汇总中分列，未将历史结果算作本版完整重跑。

紧凑布局曾在该平板内使用 420×760 dp 约束测试，不能替代另一台实体手机。尚未完成 Android 10 实机、实体纵向布局、另一台手机或 16 KiB 页设备测试；APK 静态 16 KiB 对齐检查不等于相应设备运行通过。

## 1.4 性能与使用边界

0.2.2 Debug 标准档肌肉模式曾完成约 65 秒持续手势短测：3,852 个模型呈现间隔，约 59.23 次/秒，P50/P95/P99 分桶为 16/25/25 ms，系统记录丢弃帧 0。该结果为历史短测；0.4.0 尚未完成十分钟持续性能或 Release 性能测量，不能据此保证所有机型达到 30 FPS。

体表实线用于教学示意；脏腑关系虚线只表示区域关系，不表示精确深部循行。筋膜连接只表达引用研究讨论的局部组织关系，不表示精确纤维轨迹、力的数值、症状病因或治疗靶点。口腔不支持任意张口、抬舌或翻唇动画。传统主治用于文献学习，不等同于现代临床疗效证据；本应用不提供针刺操作指导。
