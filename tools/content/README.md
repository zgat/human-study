# 1 离线穴位内容构建

本目录将目录、定位、三维锚点、路线及用途说明分别维护。修改用途或颜色无需重算穴位坐标。

## 1.1 目录与锚点

完整重建先准备 `requirements.txt` 中的依赖，使用 `fetch_sources.py` 下载标准资料，并完成模型资产构建。随后运行 `python3 tools/content/build_all.py`，依次生成标准目录、三维锚点、经络路线、用途说明和配色，再执行内容验证。模型重建输入、原始标准 PDF 与课件保存在忽略的 `source/` 或 `sources/`，不进入安装包；常规 Android 构建直接使用随源码提供的成品资产。具有明确许可的 TARA 正式发布本体作为独立原件随包提供，见 1.6。

目录包含 GB/T 12346—2021 的 362 个经穴和 GB/T 40997—2021 的 51 个常用经外奇穴，共 413 条目、843 个显示实例。印堂编号为 GV24+；金津玉液合为一个条目、两个位置；夹脊包含胸1至腰5共34个左右位置。定位文字保留标准条款和模型参照，不含针刺或艾灸操作。

坐标针对 BodyParts3D 成人男性模型，单位米、Y向上、正面+Z、人体左+X。锚点保存源表面、源顶点或三角形及重心坐标。`provisional` 表示教学定位，几何核验通过不能代替医学审校。口鼻、会阴及足底等部位保留局部观察信息。经络路线仍属教学示意，脏腑关系线不表示精确深部循行。

缺盆、气户、库房的六个左右侧实例使用上胸局部几何参考：沿用本模型既有的 4 B-cun 教学旁开列，结合锁骨上下缘及第一肋间的体表投影分开三个高度，不将该列解释为个体骨度测量。需要重建这三个条目时，在已准备原模型输入的环境运行：

```sh
python3 tools/content/anchor_points.py --point-ids st12 st13 st14
python3 tools/content/build_meridians.py
python3 tools/content/validate_content.py
```

这条命令局部更新六个锚点，保留其他穴位、条目文字与既有标志点；结果仍标为 `provisional`，专业医学审校完成数为 0。

标准资料采用公开副本；经外奇穴资料与正式出版文本的逐条复核仍未完成。公开阅读不表示原资料具有开源许可，原始 PDF 和课件不随成品分发。

## 1.2 用途说明

`function_notes.json` 保存 413 个条目的短摘要、明确出处和核对状态。`update_functions.py` 将其写入离线目录；运行时由 Room 内容哈希触发更新，不需要改变数据库表结构。

```sh
python3 tools/content/update_functions.py
```

当前范围为 408 条传统主治摘要、1 条乳中定位参考说明，以及 4 条联合用穴或研究背景。急脉、新设、腰宜、肩前这 4 条的传统主治范围仍待权威教材或标准逐条核对，显示文字明确说明其资料性质。全部内容的专业医学审校数为 0，不应视为已验证的单穴临床疗效。

资料逐穴匹配，优先使用上海中医药大学公开课件的当前幻灯片，缺少明确记载时从《针灸大成》《经穴汇解》的清楚病证文字或其他具名来源补充，并标明历史记载；当前主来源包括 212 条大学课件和 185 条《针灸大成》。电子原典有缺字和古今异名，仍需对照扫描底本及专业审阅。其余条目记录机构公开资料、具名医师说明或已发表的用穴资料。原课件、标准 PDF、网页和操作说明不进入安装包。

旧课件编号可能与 2021 年国标不同，尤其是印堂、翳明、颈百劳、腰眼、十七椎及内膝眼。本目录按名称和上下文匹配来源，保留旧编号供核查，避免以旧编号覆盖当前条目。归来所在课件页面先列多个穴位的位置，主治段按“归来”的穴名释义匹配，不误挂到列表末尾的气冲。

来源条目及已取得文件的 SHA-256 随 `function_notes.json` 保存，导出的源码无需原下载目录也能重建同一份用途说明。`manifests/content-functions.json` 记录覆盖与未核边界。GB/T 30233—2013《腧穴主治》的官方状态已核验为现行，但尚未完成全文逐条对照，不能将其写成已完成的数据依据。

## 1.3 经络配色

`meridian_definitions.py` 是 20 类经络颜色的唯一输入。以下命令使用 NumPy 校验确定性配色，只更新路线颜色，保持路线几何与穴位关联不变。

```sh
python3 tools/content/update_palette.py
```

配色采用 sRGB 候选网格和 CIELAB 最远点选择。20 色唯一，当前最小 CIE76 色差为 28.27，对暗面板 `#14222D` 的最低对比为 5.04:1。这些数值不代表人体模型表面的最小对比，也不保证所有色觉差异下均能分辨 20 色；目录名称、单独开关与选中强调应同时保留。

## 1.4 验证

```sh
python3 tools/content/validate_content.py
```

完整几何验证需要构建期间保存的模型源数据和 NumPy。验证目录数量、定位引用、843 个锚点、20 类路线、逐穴用途字段、来源、用途核对状态及颜色唯一性。用途更新额外比较全部非用途字段的语义指纹，确保 ID、归经、定位和锚点均不变。通过数据一致性检查不等于通过医学审校。

## 1.5 筋膜连接与组织范围

```sh
python3 tools/content/build_fascia.py
```

筋膜内容独立读取已交付的标准／流畅 GLB 和 `anatomy.json`，不需要重建模型或穴位数据。生成器输出 `content/fascia.json`：局部连接虚线引用连接参考区；组织范围实线在实际网格上沿共享边三角面路径取样，每个样本保留节点、三角形、重心坐标和法线。实线仅帮助辨认组织范围，不表示纤维轨迹或受力方向。

几何检查包括样本表面重建、侧别、相邻采样间距、标准／流畅档表面差异、来源与缺少组织的说明，以及原有连接参考区保持。完整结果保存至本地 `manifests/fascia-content.json`，公开摘要见 `docs/validation/fascia-content.json`。医学定位与模型配准仍待专业审校；通过几何检查不能作为临床定位依据。

## 1.6 TARA 独立原文

TARA Acupoints Ontology 的正式发布文件 `acupoints-1.7.2.ttl` 位于 `app/src/main/assets/third_party/tara/`，固定上游提交 `7c05c8407f6e529bc839d34109e67ab00c642c73`。原文件逐字节保留，运行时只读解析允许展示的原文字面量，不翻译、修订拼写或写入 Room 中文内容库；解析器针对该固定发布格式，不是通用 RDF 推理器。来源、作者、精确文件哈希及许可全文见 [TARA 来源说明](../../licenses/TARA-NOTICE.md)。

在仓库根目录运行以下命令，完全离线校验正式本体、两处许可全文和署名说明的一致性：

```sh
python3 tools/content/fetch_tara.py
```

仅在固定输入缺失且需要联网获取时，显式运行 `python3 tools/content/fetch_tara.py --fetch`。脚本核验固定 URL 和 SHA-256，已有文件不被覆盖。常规 Android 构建与首次启动不执行下载。

TARA 文字对应本应用 395 个条目、396 份来源记录；金津、玉液关联同一国标条目但分别保留原文。记录保留术语 IRI、原件起始行和出版物引用；印堂使用来源的 EX-HN3 对照国标 GV24+，其他未对应条目不补造资料。多点奇穴不拆成多份来源记录，也不新增三维锚点。

穴位详情可单独展开 TARA 的英文定位、传统用途、血管和神经说明，缺少的属性不生成内容。面板提供离线署名、许可和固定版本上游链接。原本体中的针刺或艾灸操作属性保持在原件中，但不进入展示白名单。TARA 资料不提供本模型的坐标校准或专业医学审校。
