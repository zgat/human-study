# 1 人体研究

[源码仓库](https://github.com/zgat/human-study) · [下载最新版](https://github.com/zgat/human-study/releases/latest)

当前版本为 **0.5.0**。

面向 Android 手机和平板的中文离线人体图谱。提供成人男性皮肤、分层肌肉、内脏、骨骼、经络和穴位浏览，所有模型与资料随安装包提供。

## 1.1 安装

- 系统：Android 10 或以上，arm64-v8a，支持 OpenGL ES 3.0。
- 安装文件：[human-study-0.5.0-arm64.apk](https://github.com/zgat/human-study/releases/tag/v0.5.0)。
- 安装后首次打开即可断网使用，无需账号或下载资源包。
- 当前 APK 使用本地测试签名，供直接安装验证；正式商店发行应使用独立保管的发布签名。

## 1.2 使用

- **综合图谱**：使用“体表／内脏透视／骨骼”观察预设，在解剖目录中按系统查找结构。
- **经络穴位**：目录只保留“经络路线／经外奇穴”，展开经络查看所属穴位，常用奇穴按身体部位展开。打开目录时自动展开并滚到当前高亮穴位；已有搜索词时保留查询，仅在匹配结果中定位，清空搜索可返回所属分组。经络页提供“经络全选／经络全不选”和“全部展开／全部收起”，奇穴页提供对应操作。勾选与展开分别控制，操作只作用于当前分类；经络全不选仍保留高亮穴位的归经显示，取消选点后按勾选集合显示。名称、拼音、别名和标准编号始终全局搜索，不受当前分类限制。勾选路线时以细描边突出；点按人体附近的穴位或点选目录条目，会同步开启并突出所属经络。切换内脏／半身透视或临时勾选其他经络，保留已选穴位和归经高亮；勾选另一经络仍会突出该路线，穴名继续只显示所选穴位归经。
- **筋膜解剖**：默认浏览真实筋膜、腱膜和支持带，可搜索并独显对应组织；“文献连接”另列七组局部研究关系。局部关系线、组织范围辅助线和参考区可独立开关，组织范围辅助线默认关闭。各组分别列出解剖连续性、实验加载或人体间接观察的研究条件与边界；这些类别不表示证据强弱等级，也不构成全身标准力线。
- **同名组织整体操作**：同名且属于同一来源解剖概念的多个片段，在目录中合为一项。点选任意片段会高亮整体；隐藏、独显和镜头定位均作用于整组。回肠近侧部、中部与远侧部分别处理，名称区分左右的结构仍可独立操作。
- **肌肉解剖**：默认仅显示肌肉，提供“全部肌肉／浅层／中层／深层”快捷观察；目录按头颈、躯干、上肢、下肢筛选，骨骼可作为参照开启。点选或目录定位保留其他肌肉；单片结构“隐藏这一块”，多片同名结构整体隐藏，其他结构保持原状；“单独显示”是独立操作。肌肉总开关会保留细分开关状态。
- 三个模式都提供“肌肉／骨骼／内脏／皮肤”快捷开关，可独立显示或隐藏；重新打开肌肉会保留分层与单块隐藏设置。图层面板提供相同控制。
- 切换模式会同步切换目录、主要工具和相关说明卡，同时保留各模式的搜索与图层设置；三个模式复用同一模型和相机。
- 单指旋转，双指缩放和平移；右侧按钮切换正、背、左、右视角或复位。
- 点选部件查看中文说明，展开后可单独显示或隐藏该部件。穴位卡片浮在模型窗口内，提供定位、解剖关系和传统主治资料；展开查看完整内容及来源时，模型窗口也保持原尺寸。目录定位后，左下角返回按钮恢复此前的图层与视角。
- 经络模式提供体表、内脏透视、左半身透视和右半身透视；左右以人体自身为准。半身透视按正中矢状面裁开指定侧的皮肤、肌肉及眼球外表面、口唇和牙龈，保留另一侧肌肉与五官外观；深部内脏、骨骼和牙齿完整显示，原有穴位坐标保持不变。
- 默认只显示经络点和线；点选穴位后才显示该经络的穴名，经外奇穴仅显示当前条目名称。中文名称仍受图层总开关控制。
- 经络页快捷栏和图层面板都提供“脏腑关系线”开关，默认关闭；开启后只显示已勾选经络的关系线。其虚线连接相关脏腑区域，不能作为精确深部经络路线。图层面板分别控制经络线、穴位标记、中文名称和说明卡。标准、流畅两档模型保持相同坐标和部件编号。
- 口腔、鼻内、会阴、足底等条目提供局部观察视角；口腔与鼻内视图会隐藏外层、保留相关真实结构。
- 平板或宽屏显示侧栏，紧凑屏幕使用底部面板。

## 1.3 内容与模型

穴位目录依据 GB/T 12346—2021 的 362 个经穴及 GB/T 40997—2021 的 51 个常用经外奇穴，共 413 个条目。双侧、组穴和多个位置分别保存为 843 个显示实例；413 并非三维标记的总数，也不是历代经外奇穴全集。

十二正经与奇经八脉共 20 类路线。任督二脉只保存一份；其余六条奇经关联已有交会穴，不另造穴位编号。实线表示体表路线；默认关闭的虚线用于脏腑关系示意，不表示精确深部循行。

基础模型为 BodyParts3D Release 4.0，补充肌肉来自 Z-Anatomy。两档模型均包含 1291 个独立部件，对应 1112 个交互组；Z-Anatomy 结缔组织补充共 60 片，包含 44 片筋膜或腱膜及 16 片支持带。本版新增 52 片网格，原有部件和穴位锚点几何保持不变。结构分类为肌肉、骨骼、器官、皮肤、筋膜等结缔支持组织和解剖腔隙参考；不同结缔组织分别标注类型。整体肌肉深度分组按区域编排，不代表全身存在统一的三层解剖平面。

BodyParts3D 原件采用 CC BY 4.0；包含 Z-Anatomy 肌肉补充的合并模型按 CC BY-SA 4.0 提供。来源、修改、许可证及几何配准边界见 `licenses/MODEL-NOTICE.md`，应用内“关于 → 来源与许可”可离线阅读。

## 1.4 构建与设备连接

构建需要 JDK 17 或以上、Android SDK Platform 37.0 与 Build Tools。应用的最低运行版本是 Android 10；编译 SDK 版本不等于最低运行版本。Gradle Wrapper 和 Filament 1.78.0 固定依赖已包含，首次构建还需要下载 AndroidX 等依赖。

```bash
./tools/build.sh :app:assembleRelease :app:testDebugUnitTest
```

输出为 `app/build/outputs/apk/release/app-release.apk`。脚本优先使用项目 `.tools/android-sdk`；在其他环境可通过 `ANDROID_HOME`、`JAVA_HOME` 配置已安装的工具。需要安装平台时，其 SDK 包名为 `platforms;android-37.0`。

设备首次通过无线调试完成配对后，绑定一次当前连接地址：

```bash
python3 tools/device.py --address 当前IP:连接端口
```

之后不再填写地址：

```bash
python3 tools/device.py
python3 tools/device.py -- install -r 下载目录/human-study-0.5.0-arm64.apk
```

脚本优先识别已连接的目标设备，随后通过 mDNS 获取当前无线调试端口，并核对设备身份。不会把某个历史 IP 或端口作为固定地址，也不会自动连接其他手机。无线调试需保持开启；关闭调试、跨局域网或设备撤销配对后，需要恢复对应条件。

## 1.5 验证与限制

所有穴位锚点均绑定真实模型表面，保存了源网格与几何证据；这能验证标记落在模型上，不能证明其医学定位已经正确。当前三维定位与经络路线为教学示意，仍需逐条专业校对，医学审校完成数为 0。

部分经外奇穴定位整理依据公开标准副本，仍需与正式文本逐条复核。剩余共点与左右形态差异保留在 [内容核验](docs/validation/content-validation.json)。模型补充的配准、肌肉分层及中文解剖内容同样保留审核边界。

用途资料覆盖 413 条目，其中 408 条为传统主治摘要，乳中为定位参考；急脉、新设、腰宜、肩前提供联合用穴或研究背景，其单穴主治范围仍待核对。每条保留来源，不将组合用穴资料写成单穴疗效。

口腔内部仅展示当前真实网格中已有的局部结构，不提供任意张口、抬舌或翻唇动画。传统主治用于学习中医文献，不等同于现代临床疗效证据，内容仍待专业审校。本应用不提供针刺操作指导。

构建、数据、几何、设备安装和运行测试分别记录，详见 [公开验证资料](docs/validation/)。真机结果只适用于报告中的设备与条件，不作为所有 Android 设备的性能保证。

筋膜命名基准、连接链与触发点的区别及当前覆盖见 [筋膜与连接链说明](docs/筋膜与连接链说明.md)。

验证条件、通过项目和未完成范围见 [验收报告](docs/验收报告.md)。[Release](https://github.com/zgat/human-study/releases/tag/v0.5.0) 提供可安装 APK、包含模型的源码包及 SHA256SUMS。
